# Warsaw Traffic Simulation

**A C++ ASCII-based simulation of Warsaw's road network with moving cars and trucks.**

## Features
- ASCII map of Warsaw (45x45)
- Cars (`c`) and trucks (`T`), **trucks move twice slower**
- Roads (`-`, `|`) and intersections (`+`)
- Random start and destination for each vehicle
- Map refreshes every **0.5 seconds**

## Technologies
- C++ (Xcode / Terminal)
- ASCII rendering in console
- GitHub Projects (Board view for task tracking)

## Project Files
- `main.cpp` – main simulation code  
- `mapa.txt` – ASCII map of Warsaw  
- `README.md` – project documentation
